# Design notes

Concept: a hardware control deck. Graphite panels, an amber signal light,
LED status dots and segment meters. The usage meters are the one bold
element; the rest stays quiet.

Tokens (dark): graphite #1e2124, rail #1a1d20, panel #23272b, line #3a3f45,
ink #e6e3dc, amber #e8a33d, LED green #6bcb77, LED red #e5534b.
Light mode uses aluminium greys and a darker amber for text.

Type: IBM Plex Sans for the interface, IBM Plex Mono only for code,
commands and tool output.

Avoided on purpose: Claude terracotta, cream with serif, acid green,
same-shadow cards, all-caps labels, glow, badges on list items.

Status colours: green = done or connected, amber = running or waiting,
red = error, hollow = off.
